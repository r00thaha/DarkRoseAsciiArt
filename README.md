# 4-U: 3D ASCII Flower

An interactive 3D ASCII flower animation rendered in real time using HTML5 Canvas and vanilla JavaScript. Features procedural stem growth, dynamic petal blooming, custom depth buffering, directional lighting, organic wind physics, and water reflections.

## Features

- Procedural 3D ASCII rendering engine built without external dependencies
- Custom Z-buffering (depth buffering) for precise character layering
- Directional 3D lighting, ambient occlusion, and rim highlights
- Smooth blooming animation with 42 procedural 3D petals
- Wind physics with realistic stem swaying and leaf flutter
- Dynamic environment with floating fireflies and a rippling water reflection
- Fully responsive fullscreen canvas scaling

## File Structure
.
├── index.html
├── style.css
└── script.js


## Getting Started

1. Clone or download this repository.
2. Place `index.html`, `style.css`, and `script.js` in the same directory.
3. Open `index.html` in any web browser.

## Interaction

- Click or tap anywhere on the screen to reset and replay the growth animation from the beginning.
